The perceptron algorithm and support vector classifiers

Author

Ryan Giordano

Goals

    • Show that it is performing empirical loss minimization
    • Prove that it generalizes when there is a margin using stability analysis rather than a uniform law of large numbers
  • Introduce support vector classifiers as a generalization of the perceptron algorithm

The perceptron algorithm

The perceptron algorithm is a way of training linear classifiers when there exists a separating hyperplane for a particular set of features. Specifically, suppose that you observe \((\boldsymbol{x}_n, y_n)\) and there exists a \(\boldsymbol{\beta}^{*}\) such that

\[ y_n = \mathrm{I}\left(\boldsymbol{x}_n^\intercal\boldsymbol{\beta}^{*}\right) \textrm{ for all }n\in\{1,\ldots,N\}. \]

When there exists such a \(\boldsymbol{\beta}^{*}\), it turns out that there is a simple algorithm for finding it, the “perceptron algorithm,” with provable generalization error. The perceptron algorithm is not necessarily practical support vector classifiers (or the related support vector machines) are typically used instead. (See Hastie, Tibshirani, and Friedman (2009) Chapter 4.5.1 for a discussion of some practical problems with the perceptron algorithm.) However, the perceptron algorithm is interesting because

  • Even though it does not appear superficially to be performing empirical loss minimization, we can find a loss that admits this interpretation and
  • We can prove that it generalizes in a new way: by analyzing the stability of the particular algorithm rather than by a ULLN.

There is no need to reproduce the text of Chapter 3 of Hardt and Recht (2021) here. The key ideas are:

  • The perceptron algorithm is operationally defined
  • The perceptron algorithm makes sense, in that it moves the margin to improve its mistakes, and ignores its correct classification
  • The perceptron algorithm can be rewritten as stochastic gradient descent on the hinge loss
  • Without doing any statistics, you can prove that the perceptron algorithm makes a finite number of mistakes (Chapter 3, Theorem 1, Hardt and Recht (2021))
  • The bound on the number of mistakes guarantees that you find a separating hyperplane on any dataset where one exits
  • The bound on the number of mistakes controls the generalization error by a simple IID argument (Chapter 3, Theorem 2, Hardt and Recht (2021))

Of particular interest to us is how we get strong generalization bounds by carefully analyzing a particular algorithm for performing empirical loss minimization.

The support vector classifier (or soft margin classifier)

A solution to some of the practical difficulties of the perceptron algorithm is to define more precisely which of the many possible separating hyperplanes we want. One key idea is to maximize the margin, or the minimum distance of any point to the hyperplane.

This leads to a family of maximum–margin estimators, which can be written as constrained optimization problems (Hastie, Tibshirani, and Friedman (2009) 4.5.2):

\[ \min_{\boldsymbol{\beta}} \left\Vert\boldsymbol{\beta}\right\Vert_2^2 \textrm{ subject to } y_n(\boldsymbol{x}_n^\intercal\boldsymbol{\beta}+ \beta_0) \ge 1 \]

One of your homework problems will be to work through some of the details, and we’ll provide intuition in the lecture. When a separating hyperplane does not exist, one can use a soft–margin classifier (Hastie, Tibshirani, and Friedman (2009) 12.2),

\[ \min_{\boldsymbol{\beta}} \left\Vert\boldsymbol{\beta}\right\Vert_2^2 \textrm{ subject to } y_n(\boldsymbol{x}_n^\intercal\boldsymbol{\beta}+ \beta_0) \ge 1 - \zeta_n \textrm{ and }\zeta_n \ge 0, \sum_{n=1}^N\zeta_n \le C. \]

If \(\zeta_n > 1\), then the point is misclassified; this is allowed in the soft–margin classifier, but no more than \(C\) times. The quantity \(C\) is a tuning parameter which governs the degree to which you get a bumpy boundary that classifies things correctly or a smooth margin that makes some errors. As usual, \(C\) can be set by cross-validation.

The soft–margin classifier is particularly well motivated when you have a highly expressive set of regressors which can in principle produce a separating hyperplane, but which might be very bumpy in the original space, and which you want to regularize with \(C\). Kernel methods, which we will discuss at the end of the course, will provide a such a setting, and lead to “support vector machines.”
